PHASE 1: SYNTHETIC TRAINING DATA GENERATION
==============================================================================

Create file: ml/training_data_generator.py

Requirements:
- Generate 150 synthetic battery cycles with realistic degradation patterns
- Use physics-based models:
  * Peak separation (ΔEp): starts at 59 mV, increases with degradation (59-300 mV range)
  * Reversibility index: starts at 0.1, increases with degradation (0.1-1.0 range)
  * Noise index: starts at 0.05, increases with degradation (0.05-0.3 range)
  * SEI thickness: starts at 1 nm, increases with cycles (1-100 nm range)
  * Peak current (Ipa): decays exponentially with cycles
  * Charge-transfer kinetics proxy: degrades with cycle count
  * Diffusion coefficient proxy: decreases with degradation
  * Stability index: decreases from 0.9 to 0.5 as battery ages
  * Consistency score: decreases from 1.0 to 0.6 as degradation increases

- SoH (State of Health) calculation:
  * Start at 100% for new batteries
  * Degrade non-linearly following realistic battery aging curves
  * Final SoH range: 20-100%
  * Include realistic degradation rates (0.5-2% per cycle)

Output CSV format:
```
delta_ep,reversibility_index,noise_index,sei_thickness,ipa_decay_rate,kinetics_proxy,diffusion_proxy,stability_index,consistency_score,cycle_count,soh
```

- Save as: ml/training_data.csv
- Include docstring explaining physics-based parameters
- Add reproducibility (set random seed)
